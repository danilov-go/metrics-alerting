# Сервис сбора метрик и алертинга

Микросервисное приложение на Go для мониторинга системных показателей.

## Сборка проекта

Для компиляции компонентов с автоматическим вшиванием версии, даты, коммита через флаги линкера (-ldflags -X), выполните команду из корня репозитория:

```bash
make build
```
## Запуск приложения с асимметричным шифрованием

Для защиты передаваемых данных приложение поддерживает асимметричное шифрование. Перед запуском необходимо сгенерировать пару RSA-ключей. Для этого выполните команду в терминале из корня репозитория:

```bash
make generate-key
```
В результате выполнения команды в корне проекта появится директория certs с сгенерированными ключами.

При запуске компонентов необходимо передать путь к соответствующему ключу шифрования. Сделать это можно одним из следующих способов:

### Через флаги командной строки:
```bash
# Запуск Сервера 
./server -crypto-key certs/private.pem

# Запуск Агента
./agent -crypto-key certs/public.pem
```

### Через переменные окружения:
```bash
# Для Сервера
CRYPTO_KEY="./certs/private.pem"
./server

# Для Агента
CRYPTO_KEY="certs/public.pem"
./agent
```
### Через JSON-конфигурацию:

Также можно вынести все настройки в JSON-файл. Шаблоны-образцы конфигураций находятся в папках соответствующих компонентов:

 `cmd/server/config.example.json`
 `cmd/agent/config.example.json`

Передать путь к рабочему файлу конфигурации (например, `config.json`) можно следующими способами:

#### С помощью флагов командной строки `-c` или `-config`
```bash
# Запуск Сервера 
./server -c cmd/server/config.json

# Запуск Агента 
./agent -config cmd/agent/config.json
```

#### С помощью переменной окружения `CONFIG`
```bash
# Запуск Сервера
CONFIG="cmd/server/config.json"
./server

# Запуск Агента
CONFIG="cmd/agent/config.json"
./agent
```
